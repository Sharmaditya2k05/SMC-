# Stitch prompts – S.M.C redesign

Direction: **scroll storytelling**, in the **logo's colours** (charcoal, warm white, orange glow). Ten pages, one prompt each.

## How to use

1. Start one Stitch project, choose **Web**, and paste **Prompt 0** first. It sets the theme every later screen inherits.
2. Paste the page prompts one at a time, in order. Each is written to stand alone, so it also works if Stitch loses the theme – in that case paste the "Style line" (below) in front of it.
3. After each desktop screen, send the **mobile follow-up** at the bottom of this file.
4. Upload the teacher photo and the SMC logo to Stitch when it asks for images, so it does not invent a person.

**Style line** (paste before any page prompt if the theme drifts):

```
Style: premium mathematics coaching brand. Charcoal #16171B, graphite #2B2D33, warm white #FBF6F3, white cards, ember orange #F5861F used sparingly as a glowing accent, amber #FFB648 for highlights, ash grey #7B7F87 for secondary text. Headings in Sora (bold, tight), body in Inter, small maths annotations in an italic serif. Thin orange arc lines and faint graph-paper grids as decoration. Slightly squared corners (8px), no cartoon icons, no graduation caps, no heavy gradients.
```

## Prompt 0 – theme and shared parts

```
Create the design system and a style-guide screen for "S.M.C – Siddhu Mathematics Classes", a personal-brand website for a Mathematics teacher who teaches Class XI and Class XII. The mood is premium, intelligent and warm, taken from the logo: a glowing light bulb with an orange orbit ring and a bold black SMC wordmark.
```

## What Stitch cannot show

Stitch produces still screens, so the scroll behaviour is described as layout (pinned panels, chapter sections, progress dots). The actual motion – pinning, the highlighted point moving along the curve, columns drifting at different speeds – is built in code afterwards. When you have screens you like, export or screenshot them and they can be implemented on the existing site without changing the admin, notes library or enquiry form.
